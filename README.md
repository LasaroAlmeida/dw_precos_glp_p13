# Data Warehouse para análise dos preços do Botijão de Gás GLP P13

O projeto tem como objetivo praticar a modelagem dimensional e a construção de análise sobre uma base de dados. Os dados selecionados para desenvolvimento e análise estão disponibilizados pelo gov.br.

**Site**: https://www.gov.br/anp/pt-br/centrais-de-conteudo/dados-abertos/serie-historica-de-precos-de-combustiveis \
**Seção**: GLP P13 (onde temos bases mensais a partir de 01/2023)
